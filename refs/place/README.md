# refs/place — 場所の参考画像（git 管理外）

Google マップのストリートビューを **進む順番に** 10 枚くらい、`01.jpg` 〜 `10.jpg` で置く。

- 道の正面 5〜6 枚、交差点・曲がり角 1〜2 枚、象徴的な建物・景色 1〜2 枚
- **上空写真 1 枚**（道の形と区画が分かるもの。ファイル名は `aerial.jpg` でも可）
- メモがあれば `notes.md` に（例：`03: 右に酒屋、左は田んぼ`）

番号は `src/world/course.ts` の `viewpoints` の name と対応し、Critic が同じ番号どうしを比べる。
このフォルダの画像は公開しない（`.gitignore` 済み）。
